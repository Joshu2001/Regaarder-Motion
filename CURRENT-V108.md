# V108 — surface builder, multiresolution, UV and material maps

Adds editable resolution levels with separate detail/weight layers, UV editing,
rigid-prop atlases, vertex-color painting, embedded PBR maps, color-map baking,
height-to-normal generation and recoverable topology construction.

The native editor entry is `dist/character-editor-v97.html` (header V108).
The integrated application continues to use the same shared engine/editor.
Historical reference scenes are preserved; this is a tooling release, not a
claim that all character proportions or lighting now exactly match the footage.

See `docs/v108/README.md` for instructions, API, tests and precise limitations.
