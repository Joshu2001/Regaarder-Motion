# V105 — guided Reference Fit editor tool

Open any native 3D composition, select a character or mesh, then click **Reference Fit**.
The tool is part of the shared editor, including Blank Composition and the native lab.

Upload image frames, set their local times, trace the visible outlines and optionally
pair surface landmarks. Reserve frames for validation. Preview a bounded fit, inspect
the errors, then Apply as one Undo step. Existing saved compositions are preserved.

The current handshake also uses the accepted blue-material color calibration.
Choose **Load updated handshake** to use the revised defaults.

See `docs/v105/README.md`. A synthetic sandbox scene is supplied at
`docs/v105/reference-fit-demo.json`; import it to try the tool without external media.
