# V107 — shared precision editing

Adds vertex/edge/face selection, named regions, bounded bind-local displacement,
replayable spaced brush strokes, connected-surface sculpting, dimension-correct
box rounding, navigation views, and editable prop construction. New primitives:
ellipsoid, cubic Bézier tube, revolved profile, and native indexed mesh data.
Linked table/chair/trophy builders retain component identities and materials.

Open `dist/character-editor-v97.html` through a local server. Its historical URL
is retained; the editor header reads V107. The main app in `dist/index.html` also
uses this editor. Existing reference scenes, media, rigs and templates remain.

Read `docs/v107/README.md` for controls, API, tests and unfinished plan items.
This is an editor foundation release, not a claim of an exact visual reference
match or completion of the entire professional modeling roadmap.
