# Restored V100 + anatomy controls

The actual uploaded V100 archive was recovered and its engine, direct-pose tools, subdivision, contact rig and lighting retained. The anatomy extension is now integrated, not merely tested against V98.

Enable Select body region, then tap a head, neck, chest, hand or foot. The inspector exposes neck shortening/thickness, nape/throat volume, skull width/depth/height/axis, lower-face width and chin projection. Mesh vertices and skeleton rest joints use the same continuous shape deformation. Existing scenes are unchanged until the controls or optional starting profile are used.

The optional profile is an editable candidate, not an exact reference match. The current mannequins still need visual sculpting, neck/shoulder shading correction and finger-contact refinement. No full-body physics or automatic collision-free grasp was added. No push or deployment.

Photo-to-3D remains planned: deterministic landmark fitting and manual controls, with reversible AI refinement later. A single photo cannot uniquely determine hidden surfaces.
