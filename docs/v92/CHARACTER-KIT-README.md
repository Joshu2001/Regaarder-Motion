# V92 character kit
Actual skinned geometry,163bone rig, materials and sampled neutral-scene animation are in humanoid.glb. Native-asset/humanoid.json supplies the immutable CC0 anatomical base; native-asset/garments.json supplies current smoothed clothing. Native scene recipes are under native-scenes/. Use the supplied native editor or full project to edit scene objects, bones, part fit/material tracks, head tint, pose timing and light scopes. Generic GLB viewers do not reproduce native light isolation, procedural smoke/background or material-color tracks; native JSON is authoritative. Hat-group transform tracks are sampled in GLB. This is authored reconstruction, not original production geometry or cloth simulation. No external authoring application is required. See licenses/provenance and IMPLEMENTATION-V92.md for source fidelity limits.
