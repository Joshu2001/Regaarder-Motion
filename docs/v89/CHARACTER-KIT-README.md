# Regaarder Motion V89 · editable anatomical character

The GLB contains actual skinned geometry,163bone skeletons, independent garment/accessory meshes, materials and a sampled animation. The native JSON scenes are imported through the native3D editor. They reference the bundled anatomical-humanoid-v89 asset; humanoid.json contains that asset's geometry, skin weights, skeleton and original control topology. The faceless head/neck style is generated by native3d/engine.js; the retained faceless radial candidate inside the source JSON is inactive.

The core graphical data (base mesh, supplied rig/weights and male target) are from MakeHuman and explicitly CC0. Exact URLs/hashes and modifications are in provenance.json. LICENSE.ASSETS.md is the asset license; LICENSE.md explains the split between data and application code. No MakeHuman application code or external editor is required. The project-authored code adds subdivision, fitted garment shells, a faceless head, pose/IK logic, materials and native scene/editing integration. Three.js and its bundled exporters are MIT; THREE-LICENSE.txt is included.

Open the main project → Humanoid ·3D editor, or use Blank Composition → Anatomical humanoid ·native3D scene. Clothing/materials and bones/fingers are selectable. Save native scene JSON for the complete editable recipe. Use GLB when actual geometry/skins/animation are needed outside this runtime. The native scene remains authoritative for constraints, procedural atmosphere, visibility intent and changing FOV. Rendering/import in another engine is not certified.

This is a first native editor/character foundation. Garment tailoring, collision-free contacts, per-pose volume correctives, joint limits and source matching remain refinement work. Native sculpting/topology operations are a later editor phase; the control topology is retained for them.
