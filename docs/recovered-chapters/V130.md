# Regaarder Motion Atelier V130 · 23:29–25:29

Merge this patch's dist folder into the project that already has V129. In the V129 editor or continuous review, click **V130 controls**. For a standalone preview, serve the patch dist folder over HTTP and open chapter-editor.html. The continuous review requires the existing sequence modules.

The four seconds between the V129 endpoint and V130 opening remain a timed black interval. The V130 editor has scene cues, playback speed and reversal, selected entrance direction, individual layer replacement, transforms, depth, opacity, blur, visibility, and preset export/import. Cues and default parameters are in dist/chapter-sequence.js. Procedural overlays and drawn elements also accept image replacements.

Founder portraits are individually clipped to their frame openings. Shoe and pedestal share a camera transform. Assets are separate files. Sourced portraits and marks have provenance in dist/assets/chapter130/SOURCES.md. Existing standalone art provides the warehouse, wall, corridor, footwear, crowd, notes, and supporting plates. The vintage boot is a placeholder for the Predator and Puma shoes. The crowd and athlete staging, fire, paper, shelf, portrait compositing, and transitions are approximations. The cut does not include narration.

To render locally, install @napi-rs/canvas and FFmpeg, then run node scripts/render-chapter.mjs output.mp4.
