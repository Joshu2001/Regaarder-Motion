## Editing

Choose an image, replace it, then adjust position/size. Existing motion remains. Each of six shoes has an independent binding, entry delay, travel duration and exit timing. Profiles, diners, coffins and inset portraits have separate bindings. The Pelé/carriers/flag celebration remains a coherent contact group. Save preset + images to retain replacements; saved video replacements are supported in the Archive slot. Original-source tags distinguish archival photos, reference excerpts and generated reconstructions.

Animation controls are collapsed below the basic controls. Amount text is editable. Speed/reverse, blur/depth, crop/punch, TV screen mask/reflection, handshake bob, bill field, shoe paths, panel timing/direction, flow blend strength, coffin rise/direction, photo inset and grave outline controls are available. Replacement video defaults to raw-video mode; the supplied reference excerpt uses a crop schedule to remove its original wrapper. TV screen and coffin photo masks are adjustable; arbitrary replacement furniture does not automatically determine new mask geometry.

The small archive excerpt is loaded as a local Blob for reliable seeking on simple static servers that lack HTTP byte ranges. Browser playback is muted and advances the same source clock as the native renderer.

## Reproduction and documentation

Dependencies are recorded in package.json (install them locally for the optional CLI checks/render). Browser viewing only needs the static files.

Native renderer: `node --expose-gc scripts/render-legacy-v128.mjs --video` (requires @napi-rs/canvas; reads CODEX_PRIMARY_RUNTIME_NODE_MODULES in this environment). Browser checks: `node scripts/check-legacy-browser.mjs` with Playwright/Chromium. `MOTION_CHROME` can select a local Chromium executable. Default presets, manifest hashes/bounds and JSON effect inventory are included.

To refresh metadata after an approved asset update, run `node scripts/prepare-legacy.mjs` then `python3 scripts/bind-legacy-bounds.py`; inspect masks before accepting new bounds. These scripts update metadata, not image pixels. Preserve historical source originals and verify provenance before applying archival tags to replacements.

Read docs/HANDOFF-V128.md, ANIMATIONS-V128.md, SOURCING-V128.md, VISUAL-FIDELITY-V128.md and GENERATED-PROMPTS-V128.md. The original asset-creation guidelines and earlier handoffs remain in docs.

## Fidelity limits

This is a cinematic reconstruction for review, not a frame-identical copy. Clean archival video retrieval remains unresolved: the moving footage is cropped from the supplied360p reference. The Pelé celebration and alternate profile/product poses are generated/restored derivatives, explicitly tagged as such. The KING product photograph is an official modern relaunch, not a verified original1970 boot. Original coffin portraits were retrieved from verified archival sources. Passing functional tests does not establish visual fidelity or subjective superiority.
