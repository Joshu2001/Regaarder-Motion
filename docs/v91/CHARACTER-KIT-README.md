# V91 character kit
humanoid.glb contains actual editable meshes, skins, materials and sampled animation from the neutral factory scene. native-asset/humanoid.json is the immutable anatomical foundation; native-asset/garments.json supplies the V91 continuous shirt/trouser meshes. Native scene recipes are under native-scenes/. Use the compact native editor or full source project to edit the complete recipe, materials, bones, hand/foot targets, hat fit and lighting. Generic GLB viewers do not reproduce procedural background/smoke or native constraints exactly. No external authoring app is required for the supplied native editor.
CC0 graphical anatomy/weights from MakeHuman; project-authored faceless style, clothing surfaces, hat and pose integration. See licenses and provenance. Third-party application code is not bundled.
