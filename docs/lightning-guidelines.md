# Lightning guidelines — mandatory before editing lightning

## Mistakes made in this project
1. Drew a few straight, equally thick connected segments. The result looked like a glowing stick. Correction: use irregular, tapered branches only when a bolt is actually visible.
2. Added glow around the line without lighting its surroundings. Correction: coordinate sky exposure, cloud bloom, building highlights and foreground response with the same flash envelope.
3. Used a long, steady glow. Correction: short asymmetric flashes, a weaker return flash, then rapid decay; inspect neighboring frames rather than one attractive still.
4. Confused visible lightning with illumination from off-screen lightning. Correction: classify the shot before implementing it. Factory exterior requires flash/beams only. Never insert a visible bolt there.
5. Reused a chapter-specific effect for another scene without checking reference context. Correction: maintain distinct scene controls and masks; preserve the approved earlier chapter.
6. Treated passing numerical tests as proof of realism. Correction: compare matched entrance, peak, return flash and decay frames at normal speed and slow motion.

## Shot rules
- Chapter reveal: a visible bolt may have an irregular narrow white core, restrained blue/violet bloom and fewer, finer secondary branches. Avoid regular ladder/fern patterns, uniform thickness, screen-wide opaque white overlays and persistent neon.
- Factory/building with historical emblem: source is OFF SCREEN. Use broad directional cool flashes and soft light beams across clouds and facade. NO visible channel, branching path, zigzag or stroke. Keep architectural texture readable. Respect foreground occlusion.
- Illumination must decay to the original exposure; never permanently wash out the scene.
- A blue sky/cloud treatment is separate from a lightning strike. Animate cloud movement, not merely a static blue tint.

## Required review
Read this file first. Verify the supplied reference interval. Record whether the bolt is visible. Sample before/peak/return/after; compare environmental response and layer occlusion. Check native-size output and encoded frames. Keep exact timings editable. Preserve prior assets and custom settings. State remaining approximations. Do not claim this file guarantees future memory: future agents must read project instructions.

## V81 additional correction
Do not substitute fiery orange cumulonimbus for the dim crimson storm. Moving cloud structure and short flash illumination need separate clocks. A frontal looming face with red pulses must not reuse an opposing-profile asset. Do not call the produced matte natural until native-size contours and temporal samples have been reviewed.
