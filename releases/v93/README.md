# V93 Native Character Editor

Portable V93 release bundle for the Regaarder Motion project's native, granular character editor.

## Use

Download `Regaarder-v93-native-3D-editor.zip` and extract it. Serve the extracted folder from a local or static HTTP server, then open the included editor entry page. The bundle includes the editor code, runtime libraries, and required assets.

## Included editing workflow

- Adjust and sculpt the humanoid body, proportions, silhouette, and pose.
- Refine arm direction, hand pose, head shape, hat fit and alignment, and seated contact.
- Edit materials, lighting, shadows, and scene assets.
- Work with editable character controls, rigging/weights, and pose corrections within the V93 editor.

## Scope

This is a standalone V93 editor release bundle. It does not replace or integrate into the existing main site in this commit. The archive is a portable checkpoint for further character refinement and later integration. Rendering and body controls are focused on the current documentary reconstruction workflow; this is not a general purpose replacement for Blender.

See the package's included documentation for runtime and editor details.
